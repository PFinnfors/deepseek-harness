# @deepseek-ai/dsh-client-ui-active-session

[English](README.md) | 中文

## 摘要

`dsh-client-ui-active-session` 是 Web 侧边栏会话浏览器：其浏览器半边将单个组件注册进 ui-sidebar 声明的 `sidebar.workspaces` 插槽，注册优先级低于内置的 ui-workspace 浏览器，从而遮蔽该条目，同时保留被遮蔽包的其余注册（会话横幅选择器与 `uiWorkspace` 服务）。该浏览器在普通会话浏览之上增加了“活跃状态”：每个会话默认处于活跃状态，会话行右键菜单的首项用于在活跃/非活跃之间切换；非活跃会话以及所有会话均为非活跃的文件夹，会通过主题的 `label-dimmed` 别名渲染为变暗。视图选项菜单新增“筛选”分区，可筛选出活跃会话，仅含非活跃会话的工作区不再显示。

其宿主半边有意保持为空：该插件纯属 UI，活跃集合是仅存在于浏览器内的视图状态，随浏览器重载而重置。

<a id="use-this-package"></a>
## 使用本包

浏览器的工作方式与它所遮蔽的既有区域一致：每个宿主工作区一个文件夹、松散会话归入本地化的“未分组”桶、相对时间戳、状态点，以及分组方式/排序方式视图选项。在此基础上：

- **默认活跃** — 每个会话初始即为活跃状态；在用户切换之前，没有任何内容变暗。
- **切换活跃状态** — 会话行上的省略号菜单以“切换活跃状态”为首项；选择它会翻转该会话的活跃状态。会话活跃时，菜单首行带有对勾标记。
- **变暗样式** — 非活跃会话的行与标题使用主题的 `label-dimmed` 别名；只有当文件夹内所有可见会话均非活跃时，文件夹本身才会变暗。
- **筛选活跃会话** — 视图选项新增“筛选”分区（全部会话 / 活跃会话）。在“活跃会话”下，非活跃会话被隐藏；所有会话均非活跃的工作区完全消失；空工作区也会隐藏，而“全部会话”视图仍会保留它们。
- **文件夹折叠** — 点击文件夹即可完全折叠（显示零个会话行），无论其中有多少会话；在展开的文件夹内部，长列表折叠为五个普通行并带有“展开其余”控件，空白的新会话行不受此限制，因此临时行永远不会被隐藏。

### 主题适配

该区域完全通过共享的 `--dsw-alias-*` 语义令牌与 `--ds-ease-in-out` 动效令牌渲染，因此当前启用的主题插件（例如 Tokyo Night）完全掌控所有颜色。变暗状态复用主题自带的 `label-dimmed` 别名，而非固定的调色板。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现内部细节 — 点击展开</summary>

本包遵循一条所有权规则：活跃状态属于*视图*，而非会话日志或工作区注册表，因此它作为浏览器内的组件局部状态存在，并在重新挂载时重置。模型可见或持久化的内容没有任何变化。

### 插槽遮蔽

ui-sidebar 的 `sidebar.workspaces` 插槽是 `single` 类型插槽，因此只有一个条目参与渲染：优先级最低者胜出。ui-workspace 以默认的 `0` 注册其浏览器；本插件以 `-1` 注册，遮蔽既有区域，同时 ui-workspace 自身的 apply 仍然提供 `uiWorkspace` 服务、`useWorkspaces` 根钩子与会话横幅选择器。这里的遮蔽是预期的产品行为（活跃浏览器取代侧边栏中的既有浏览器），而非组合冲突。

### 文案与本地化

所有文案均为双语且由本包持有：本包在 `dsh-client-locale` 下以 `uiActiveSession` 命名空间注册中英文词典，并在插槽注册时声明该命名空间，因此框架会合成类型化的 `t` 座位。共享的 common 词表（`cancel`、`close` 等）仍会沿查找链解析。`workspace` 命名空间仍归 ui-workspace 所有。

### 状态推导

`tree.ts` 中的纯推导（分组、单列列表、溢出折叠、状态点、相对时间）对快照输入具有确定性；组件向其传入 `useSessions` / `useWorkspaces` / `useSessionPendingInteraction` 全局钩子，并在其上应用自己的活跃过滤器。文件夹状态的两个位（展开/折叠 与 全部显示）是相互独立的集合：折叠文件夹也会重置其全部显示位，因此重新展开时总是从最初五个状态开始。

<a id="model-experience"></a>
## 模型体验

无 — 本插件纯属展示。它只渲染既有的会话与工作区状态，不发出任何模型可见的事件，也从不触及模型请求，因此无需从会话日志中重建任何内容。

#### KV 缓存影响

无。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

以下限制界定了活跃状态的生命周期与作用范围，属于当前包的约束。

- **活跃集合仅存在于视图内** — 浏览器重新挂载时（整页刷新，或侧边栏区域卸载）会重置为全部活跃。若需持久化，这是一个显式的未来选择：该状态属于产品可见、但可论证与会话相关，且目前没有现成的存储位置。
- **筛选活跃会话只会隐藏内容，不会归档** — 非活跃会话仍保留在注册表与“全部会话”视图下；该筛选只是一种查看手段。
- **无目录流插槽** — 与既有浏览器不同，该区域没有“通过应用内浏览器添加工作区”的子插槽；添加工作区使用宿主选择器路径（`pickDirectory → create → startSession`）。
